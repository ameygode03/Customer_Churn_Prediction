# Customer Churn Prediction

## Project Overview

Customer Churn Prediction is a Machine Learning project that predicts whether a telecom customer is likely to leave the company.

The project uses customer information such as tenure, contract type, internet service, monthly charges, payment method, and other services to predict customer churn.

The trained Machine Learning model is deployed as an interactive Streamlit web application.

## Objective

- Predict whether a customer will churn or stay.
- Analyze factors related to customer churn.
- Compare different Machine Learning models.
- Select the best-performing model.
- Deploy the model using Streamlit.
